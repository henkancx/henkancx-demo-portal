# HenkanCX — DemoPortal

Portal de demos interactivos de las soluciones de IA y automatización de HenkanCX.

🌐 **Live:** [demo.henkancx.com](https://demo.henkancx.com)

## Demos incluidos

1. **Snnapi** — Inspecciones inteligentes con computer vision
2. **TeleInspect Suite** — Mantenimiento predictivo telecom
3. **Contact Center IA** — Voice AI con coach en vivo
4. **Chatbot IA + WhatsApp** — Bots conversacionales con API oficial
5. **SIFED** — Gestión deportiva para federaciones y atletas
6. **Sistema Ganadero IA** — Gestión integral del hato

- Sin dependencias externas (solo Google Fonts)
